Astro Dwarf

Screens GitHub Releases Source

Tired of babysitting a Dwarf all night? Astro Dwarf is a desktop controller and unattended imaging scheduler for Dwarf II, Dwarf 3, and Dwarf Mini.

  • ScheduleUnattended DSO sessions — a Dwarf 3 scheduler and sequencer that also covers Dwarf II and Mini.
  • Multi-scopeSeveral telescope profiles from one desktop, each with its own IP, location, and session queue.
  • ControlLive HUD: view, status, camera, commands, upcoming queue, and log. Polar / EQ and Dual Lenses Locating included.
  • PlanningBuild sessions by hand, from templates, from Stellarium’s current target, or from a Telescopius CSV. Tele/wide cameras and mosaics.
  • MediaAlbum of real astro sessions on the telescope — thumbnails, capture details, stacked-frame download.

Installers

  • Windows x64: AstroDwarf-Setup-<version>-win64.exe. Per-user install; no admin. SmartScreen may warn: More info → Run anyway. Portable zip also available.
  • macOS Apple Silicon: open the .dmg, drag to Applications, then right-click Open the first time (unsigned / Gatekeeper).
  • Linux x64: AppImage, .deb, .rpm, or Arch .pkg.tar.zst.

Unsigned builds. Pushing a new version on main replaces the previous release set.

Run from source

Python 3.11+ and Git. The scheduler stays stopped until you start it from Control. Dwarf 3 and Mini live view needs ffmpeg on PATH (installers already include it).

git clone https://github.com/styelz/astro_dwarf.git
cd astro_dwarf
./start.sh          # macOS / Linux
.\start.bat         # Windows
Telescope commands come from dwarf_python_api by JC L. (stevejcl).
