 ++Work In Progress Release++

If you find any bugs or have any suggestions for the application, please create an issue here:
[https://github.com/styelz/astro_dwarf/issues/new/choose](https://github.com/styelz/astro_dwarf/issues/new/choose)

- Fixed Aladin staying blank the first time SKY is opened after a new install. It previously appeared only after restarting the app.
- Fixed Aladin not loading at all after its chart and sky survey servers went offline. Name search and the Simbad pointer work again.
- Links on the Aladin chart, such as Simbad pages, now open in a web browser. Previously, clicking them did nothing.
- TELE and WIDE no longer swap the large preview with the inset. Use SWAP to exchange them.
- The BURST panel no longer shows "Switch to photo mode for burst and timelapse" when photo mode is unavailable.
- Fixed the joystick nudge arrows being cut off at the edge of the pad.
